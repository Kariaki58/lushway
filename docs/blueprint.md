# **App Name**: Lushways Luxe

## Core Features:

- AI Styling Concierge: An intelligent styling tool that recommends the best hairstyles, braids, or grooming treatments based on a user's uploaded photo or style preferences.
- Luxe Portfolio Grid: A sophisticated, Pinterest-style gallery showcasing professional high-resolution visuals of braiding, nails, and makeup art.
- Service Discovery Suite: Premium service cards featuring icons and imagery for over 20+ specialized unisex beauty and spa treatments with smooth hover effects.
- Instant Booking Connect: One-touch sticky booking interface that transitions seamlessly to WhatsApp and call-based appointment scheduling.
- Customer Experience Wall: A refined review slider highlighting luxury salon experiences with subtle entrance animations using Framer Motion.
- Precision Maps & Contact: A specialized contact section featuring integrated Google Maps navigation to the Abak Road location and persistent hours-of-operation indicators.
- Glassmorphic Hero Presentation: An immersive entrance section using high-fashion salon imagery layered with elegant typography and fluid glass effects.

## Style Guidelines:

- Primary Color: Deep Royal Blue (#1E3A8A) conveying prestige and authoritative luxury.
- Background: Warm Cream and Soft Nude Beige (#FAF7F2, #F5E8E1) to create an airy, feminine, and visually rich atmosphere.
- Accent: Light Gold (#D4AF37) for highlights, CTA borders, and high-end detailing to evoke a 'Dubai-to-Lagos' premium feel.
- Headline fonts: 'Playfair Display' and 'Cormorant Garamond' (Note: currently only Google Fonts are supported) for a serif, formal elegance. Body fonts: 'Inter' and 'Poppins' for clean, modern readability.
- Fine-line minimalist icons with gold-fill accents, mirroring luxury spa aesthetics.
- Spacious, boutique-style grid using 'Pinterest' layouts for imagery and glassmorphic cards for services.
- Sophisticated micro-interactions using Framer Motion, featuring slow-reveal fades and soft spring-based scrolling.
